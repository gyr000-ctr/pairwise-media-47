# uvflip

## 题面（可直接粘贴）

UV 仿射变换。约束：翻转与旋转必须合成为单一 2x3 仿射并**验证正交性**（列向量单位正交，误差 ≤1e-12）；逆变换往返误差 ≤1e-9；组合满足矩阵乘法结合律（先翻后旋 = 乘）；结果取模后仍在 [0,1)；非法 rot90 与非有限输入要可区分报错；10 万次不超过 100 ms。验收：cd uvflip && python -m pytest tests -q -k uv。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 并发安全
- 非有限输入分类报错
- 性能上界按题面
