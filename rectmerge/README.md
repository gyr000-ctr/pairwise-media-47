# rectmerge

## 题面（可直接粘贴）

图集矩形合并与打包校验。约束：合并矩形必须两两不重叠且并集覆盖原集合（面积守恒，与扫描线计算结果一致）；合并必须按面积优先的贪心 + 扫描线交叉校验，复杂度不超过 O(n log n)；退化/负尺寸矩形要给出可区分的错误；10 万矩形不超过 400 ms；并发安全。验收：cd rectmerge && python -m pytest tests -q -k merge。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 并发安全
- 非有限输入分类报错
- 性能上界按题面

## 运行方式

```bash
cd rectmerge && python -m pytest tests -q
```
