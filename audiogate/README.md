# audiogate

## 题面（可直接粘贴）

噪声门。约束：双阈值迟滞（开/关不同）+ attack/release 指数包络，不得瞬时开关；跨缓冲区状态连续，相邻样本差有上界（无爆音）；增益收敛到目标值误差 ≤1e-6；100 万样本不超过 300 ms；非法参数与非有限样本要可区分报错。验收：cd audiogate && python -m pytest tests -q -k gate。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分）

- 并发安全
- 非有限输入分类报错
- 性能上界按题面
